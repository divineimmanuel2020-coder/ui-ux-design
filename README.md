# SkillForge - Freelance Marketplace UI

A modern, production-ready freelance marketplace web application built with Next.js 15 (App Router), React, and Tailwind CSS.

## Features

- Clean SaaS-style design
- Responsive sidebar layout
- Job listings and detailed views
- Freelancer profile page
- Messaging interface mock
- Fully responsive (mobile-first)

## Tech Stack

- **Next.js 15** (App Router)
- **React 19**
- **Tailwind CSS**
- **TypeScript**
- **Lucide Icons**

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/divineimmanuel2020-coder/ui-ux-design.git
   cd ui-ux-design
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Run development server
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000)
